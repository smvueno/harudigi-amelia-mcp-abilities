What the plugin does

  • Adds Amelia abilities to Easy MCP AI (does not duplicate Amelia core tools)
  • Catalog, booking, payment, and settings coverage for AI agents
  • Redacts secrets; blocks unsafe password / externalId writes
  • Requires explicit confirmation for destructive deletes
  • Updates from public GitHub Releases via WordPress’ native Update URI flow

Install in minutes

  1. Install & activate Easy MCP AI (required)
  2. Upload the release ZIP (folder must be harudigi-amelia-mcp-abilities)
  3. Activate Amelia MCP Abilities - HaruDigi
  4. Activate Amelia Booking so the abilities can run
  5. Optional: turn on auto-updates in Plugins
