Independent HaruDigi plugin

HaruDigi Booking Abilities for Amelia is an independent plugin by HaruDigi and is not affiliated with or endorsed by TMS Software (Amelia Booking).

Author: Jens Madsen · Brand: HaruDigi · Slug: harudigi-booking-abilities-for-amelia · Version 2.0.3

Seven tools

  • amelia/help — usage + safety
  • amelia/status — versions + default appointment status
  • amelia/discover — entities and examples
  • amelia/query — list / get / stats / availability / booking_options / settings
  • amelia/mutate — catalog + customers CRUD
  • amelia/book — appointments and events
  • amelia/pay — payments + payment link URLs

Connect via Easy MCP AI: /wp-json/easy-mcp-ai/v1/mcp

Safety defaults

  • notify defaults false — lifecycle gate only; ask before true
  • Manual send: amelia/book action=notify + confirm:true (template must be enabled in Amelia)
  • Booking status omitted → Amelia defaultAppointmentStatus
  • Deletes / cancel / notify need confirm: true
  • Secrets redacted; password / externalId writes blocked

Requirements

  • Easy MCP AI (required)
  • Amelia Booking 9.7+ (required for abilities to run)
  • WordPress 6.9+ · PHP 7.4+

Amelia Pro MCP

Amelia Pro also ships its own MCP HTTP route. This plugin targets Easy MCP AI only and does not configure Amelia’s adapter. While active it unregisters Amelia’s native abilities from the Abilities API so Easy MCP does not expose duplicates; deactivate to restore them.
