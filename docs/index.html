What the plugin does

  • Extends Amelia’s built-in MCP abilities (does not duplicate core tools)
  • Adds catalog, booking, payment, and settings abilities for Easy MCP AI
  • Redacts secrets; blocks unsafe password / externalId writes
  • Requires explicit confirmation for destructive deletes
  • Updates from public GitHub Releases via WordPress’ native Update URI flow

Install in minutes

  1. Install & activate Amelia Booking
  2. Upload the release ZIP (folder must be harudigi-amelia-mcp-abilities)
  3. Activate the plugin; enable abilities in Easy MCP AI
  4. Optional: turn on auto-updates in Plugins
